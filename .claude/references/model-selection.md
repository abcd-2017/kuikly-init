# 模型选择指导

根据任务复杂度选择 subagent 模型：

| 复杂度 | 场景 | 推荐模型 |
|--------|------|---------|
| **低** | 单文件修改、简单 Bug 修复、配置调整 | `haiku` |
| **中** | 多文件功能开发、跨平台适配、重构 | `sonnet` |
| **高** | 架构设计、复杂调试、技术选型 | `opus` |

## 原则

用能满足任务需求的最低级别模型，节约成本。

## 默认值

未指定 model 时，继承父 session 的模型。如父 session 模型不支持（如某些模型不可用于 subagent），需显式指定。
